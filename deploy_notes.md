Customer Request Wizard: Added a brand new "Customer Wizard" panel at the bottom of the master tab! You can upload an Excel/CSV file containing customer requests, and a floating transparent widget will guide you through mapping each item one by one. It includes automatic global searching based on the item description, and options to skip items or insert section headers directly.
State Tracking: The wizard now tracks the exact state of every item you're mapping with color-coded checkboxes right inside the table: Header Added (Blue), Done (Green), and Skipped (Red). The logic is smart enough to handle undoing headers if you skip an item, and it won't mark an item as "Done" if you only added a header!
Clear List Enhancements: The "Clear List" button in the Offer List Dialog now prompts you with two options: to simply clear the offer list, or to clear the offer list AND completely reset your mapping progress in the Customer Wizard.
UI Polish: Added an expandable view toggle to the wizard panel so you can fit everything perfectly onto one screen without messy scrollbars. Redesigned the floating widget's close button to be a highly visible red circle so it doesn't get lost in the dark mode background.
Unmerged Section Headers: I completely removed the cell merging logic in both the internal UI table and the Excel exporter. Now, when a Section Header is added, it will apply that gray background row-wide, but the title itself will be printed perfectly isolated inside the "DESCRIPTION" column. The other columns will be empty but properly styled.
Multi-Select Enter Addition: I updated the table's event listener! You can now highlight as many rows as you want in the Master Table (using Shift+Click or Ctrl+Click), and when you hit the Enter key, the application will iterate through every single selected row and automatically add all of them to your Offer List in one fell swoop.
